# 开局准备、夜间交接与座位核对

日期：2026-10-26。源码与本地验收完成；实际发布和部署状态见[该版本 Release](https://github.com/Olalall/AI-The-Storyteller-of-the-Blood-Stained-Clock-Tower/releases/tag/opening-preparation-20261026)。

## 行为变化

- 配板人数检查与秘密准备分开核对。谜师固定目标、炼金能力、小精灵实际来源与计划告知、疯子假身份/同等人数假爪牙/三张善良假伪装，以及自定义能力和关键词，随明确确认一起保存。
- 炼金的开局人数修正参与既有检查，获得能力沿用现有授予事件和夜序，真实身份不变。任何准备失败均保留草稿。
- 罂粟阻止相认时仍给真恶魔三张未在场善良伪装及疯子身份。有效罂粟死亡后可显式补入同夜相认，完成后返回原本未处理项；有效魔术师进入指认候选，不作为邪恶接收者被唤醒。
- 疯子按假恶魔的目标要求先行动，不产生真实死亡。真恶魔行动前核对该次选择，来源更正后须重新确认交接。
- 小精灵实际标记、原始镇民与实际告知分开保存；根据已录毒醉和涡流核对信息。错误信息与继承的具体组合未核实完整裁定时，问答返回已知边界，能力授予必须明确人工复核，不能把模型推断当规则。
- 目标按钮同时展示座位、角色、生死与毒醉，可展开完整来源标记。保密遮蔽继续隐藏秘密信息。配板及状态卡复用既有角色图标组件。
- 最后一项先确认，再明确结束夜晚并进入白天。未处理事项、相认、纠错和编辑保护仍须通过既有检查。
- 博学者可换一组、采用带真假及当前角色计数依据的本地草稿；有效涡流下两条均假。生成不会自动发送、改状态或消耗次数。

参考了[钟楼灯下免登录试玩](https://botc-copilot.app/demo)的座位与操作同时可见、分步骤处理和明确完成状态。设置页需要登录，未查看其设置内容；未复制其源码、图像或内部实现。

## 数据与发布边界

新准备字段可选，旧备份继续可读。已开始旧局不自动补造准备或重新施加状态；更正继续追加事件。发布只更新运行文件，保留当前对局、历史、私有设置与运维任务。角色图像依据已有清单从原来源独立安装并校验，不进入公开 Git 或运行包附件。

## 验证记录

`npm run check`：3,086 项通过、27 项真实服务测试按配置跳过，构建、PWA 与架构检查通过；另通过后端启动与公开模式隔离检查。

Chromium、Firefox、WebKit 平板尺寸各通过一条复合场景，涵盖秘密准备、两次刷新、首夜告知、最后一项明确收尾、白天角色状态展示及博学者信息。WebKit 曾在断言持久化前读到上一次异步存档，改为等待实际写入后复测通过，没有以固定延时掩盖失败。

Ego 对本项目记录 143 次成功原生指针点击，其中最终一个 12 人合成局 125 次，不含填写、选择下拉项和滚动。该局跑完两夜与首个白天，进入第 2 天；首夜 9 项全部确认，第二夜 10 项中 9 项确认、1 项死亡不适用，无跳过技能。覆盖两次洗脑来源、醉酒僧侣、罂粟处决后相认与魔术师候选、疯子假选择到真恶魔交接、实际死亡时点、博学者信息、七票表决及备份导出/恢复预览。导出的完整数据与当前局逐字段一致，关闭重开两次均保留当前局。

真实上游验收：修订后通过 3 个规则问答片段及 2 个夜间技能片段。初测抓到疯子人数/顺序误答与小精灵来源混淆；前者补齐共享依据后复测，后者改为返回已核实边界，不计为真实模型通过。博学者候选是本地生成，未冒充真实 AI。测试使用独立合成局，真实对局、私有配置、模型名称与原始日志不进入仓库。

不宣称覆盖所有板子、角色组合或实体 iPad。异常登记、疯狂、信息强度和复杂继承仍需说书人核对。
