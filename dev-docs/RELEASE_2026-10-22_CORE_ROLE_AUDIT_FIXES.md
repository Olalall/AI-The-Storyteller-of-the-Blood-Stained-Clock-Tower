# 核心角色与全板复核问题修复

本轮修复前一轮 215 板复核发现的共享问题，不新增板子，也不将两夜录入流程称为完整规则对局。角色录入、获得能力、真实身份和主持确认仍分别保存，AI 只提供待确认建议。

## 修复范围

- 僵怖已经推导为不唤醒时，显示具体原因并提供“确认不适用并继续”，保留草稿，不伪造夜间行动，也不允许借此夜杀。
- 增加独立的能力继承记录，支持哲学家、炼金术士、科学怪人、小精灵和食人族。主持确认后按板内夜表插入新能力，保留真实角色、阵营、旧夜间记录及恶魔原有行动。后续夜晚继续投影有效能力；撤销、来源身份变化和下一次有效处决等会停用相应待发动项。首夜互认和伪装系统步骤仍放在正确位置。
- 科学怪人的死亡或毒醉需要重新核对；小精灵须有先前告知、标记玩家死亡及主持确认；食人族须对应杀死玩家的处决。毒醉、生死、疯狂和相克不由一条能力录入自动裁定。能力来源写入备份、日记及 AI 请求，旧备份版本继续兼容。
- 共享角色合同补齐祖母、守鸦人的玩家及告知角色，钟表匠的数字，修验者的方向，将军的三种比较，召唤师首夜三个不同伪装。录入不再因角色原文是中文或英文而不同。
- 告密者给每名适用爪牙分别记录三个不在场善良角色及告知确认，不唤醒告密者本人。召唤师首夜、第三夜及普卡提前召唤例外分开处理。
- 收窄哲学家、炼金术士、科学怪人、小精灵和洗脑师的角色选项，保留炼金术士可重复在场爪牙、哲学家可选在场善良角色、洗脑师与哥布林，以及有明确毒醉标记时假信息的例外。
- 瓦釜雷鸣恢复首夜互认和恶魔伪装系统卡。新候选中的旧小怪宝座位模板改为不占恶魔座位、增加爪牙的模式，已确认旧局不重写。
- 痢蛭中途产生时可分别处理宿主初始化和应有的普通攻击，初始化未确认前不允许攻击记录。原恶魔已经行动时不提供重复攻击；仍可只初始化、后续夜晚再发动。
- 新候选排除异端的六种官方禁配，配板确认层也阻止手动绕过。古堡疑云-卡慕萝米缺少可核实合法模板的 15 人入口暂不提供，7—14 人保留；原始资料和旧 15 人对局不修改。去除修复后重复的候选，不用相同模板凑数。
- 缺少角色模板覆盖的板子显示待复核原因，不再仅凭资料齐全宣称“可直接开局”。不自动编造失忆者能力或未核实的特殊开局。
- 关夜被状态层拒绝时留在夜晚并说明原因；卡扎力首夜未应用分配时明确阻止关闭。夜间确认栏回到正常文档位置，避免遮挡长表单，同时保留原来的页面滚动和布局。

## 规则依据

本轮核对的主要依据为官方 [角色相克资料](https://release.botc.app/resources/data/jinxes.json)、[哲学家](https://wiki.bloodontheclocktower.com/Philosopher)、[炼金术士](https://wiki.bloodontheclocktower.com/Alchemist)、[科学怪人](https://wiki.bloodontheclocktower.com/Boffin)、[小精灵](https://wiki.bloodontheclocktower.com/Pixie)、[食人族](https://wiki.bloodontheclocktower.com/Cannibal)、[召唤师](https://wiki.bloodontheclocktower.com/Summoner)、[告密者](https://wiki.bloodontheclocktower.com/Snitch)及[痢蛭](https://wiki.bloodontheclocktower.com/Lleech)。按稳定角色 ID 和已知能力版本复用，不将翻译差异或旧版杂技演员误改为新版规则。

## 验证

- 完整检查通过：387 个测试文件通过，3 个条件跳过；2,969 项测试通过，19 项条件跳过。lint、类型、构建、PWA 及架构门禁通过；后端实际启动冒烟通过。
- 新增浏览器专项 12/12 通过，覆盖桌面 Chromium、Firefox、Android Chromium 视口及 iPhone WebKit 视口。检查能力继承顺序、刷新与备份保留、三个伪装录入及逐爪牙告密者记录。持久化断言等待实际保存，保留初次失败记录。
- 真实 AI 的 8 个不同片段全部取得通过结果：五种能力来源、痢蛭初始化与普通攻击、召唤师首夜。两轮共 14 次实际请求，其中首轮 6 次上游网络失败，受控复测后通过；无自动重试。这些是局部语义检查，不是 8 局完整模拟。
- 原有浏览器流程 116/116 通过，覆盖多人数卡扎力分配及当晚新爪牙、角色变化、关夜、死亡票、数字边界与追加更正。
- Ego 原生点击完成 10 个专项：僵怖、五种能力来源、召唤师、告密者、痢蛭、祖母。痢蛭另用新测试页复测，宿主未确认时攻击被阻止，随后分别保存宿主和一次普通攻击。测试使用独立本地来源和合成夹具，未操作线上旧局。早期布局、定位、等待和本地预览退出的失败记录单独保留；这些专项不计完整规则对局。

本轮没有重新逐条核实全部自制角色、所有相克组合或实体手机；模板覆盖缺口会保留待核标记。测试对局、失败截图、AI 原始响应和部署私有回执仅留本地，不进入公开仓库。

## 数据与发布约束

公开内容只含源码、测试和必要文档。个人 API 地址、密钥、访问配置及真实对局不进入 Git、发布附件或测试截图。源码与最终程序包通过实际私有值扫描。部署只切换前后端程序，备份并核对现有数据、私有配置、运维任务及旧静态资源；失败时回退本次部署前的程序，不用旧备份覆盖新对局。最终上线状态以 GitHub 合并记录和本轮部署回执为准。
