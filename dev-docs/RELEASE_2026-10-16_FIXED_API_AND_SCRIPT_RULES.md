## 本轮变化

- API 地址、Key 和模型固定在服务器。网页不保存提供商凭据；首次输入私有访问口令后，用 HttpOnly、Secure、SameSite=Strict cookie 记住设备 30 天。所有付费 AI 接口先验证权限；口令错误有限流，跨站请求被拒绝。取消授权清除此设备 cookie；轮换服务器口令使已有 cookie 全部失效。
- 上线前检查还发现 AI 曾共用归档的“本地模式”，新设备会因此根本不访问服务器模型。本轮将公网 AI 接到本站后端，归档存储仍保留原有选择，不迁移当前对局或归档。
- Windows 开机任务加载发布目录外的 DPAPI 加密配置，文件只允许 SYSTEM 和 Administrators 读取。通过临时服务器公钥传送 CMS 密文，不把明文 Key 放进代码、运行包、任务参数、TAT 命令或日志。配置损坏时关闭 AI，保留手动主持。实际约束与运维流程见 [AI_SERVER_SECRETS.md](AI_SERVER_SECRETS.md)。
- 修复真实连通测试允许客户端覆盖服务地址而复用服务器 Key 的问题。连通测试仅接受空参数并使用后端当前配置；上游重定向被拒绝，调试输出不带上游原文或凭据。
- 珀显式记录 0/1/3 目标模式；沙巴洛斯两目标、贵族三名信息对象、传教士、侍女、痢蛭和女祭司等表单按角色要求录入；阴阳师可录入两善两恶四个不同角色。草稿、备份、AI 合同及过期响应校验同步支持这些输入。
