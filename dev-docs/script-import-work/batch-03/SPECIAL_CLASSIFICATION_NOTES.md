# batch-03 特殊/小板分类记录

本文件记录不能直接按普通 7-15 人智能板子注册的来源。分类不是删除；后续如果要支持特殊玩法，需要先单独设计模板和主持流程。

## 试胆大会

- 来源：GStone edition 21100 / game 41112
- 作者：Lei的剧本钟楼
- JSON：`https://oss.gstonegames.com/data_file/clocktower/json/ct_edition_21100_69696.json`
- Hash：`sha256:3a6f94028402191f4240ff495006dcbf8cd70b3ccc7b11d26172cc3c85482383`
- 角色数：12
- 阵营结构：8 镇民、2 外来者、1 爪牙、0 常规恶魔、1 传奇。
- 关键证据：传奇「凶宅」写有 `[-1恶魔，+1善良玩家]`，并由说书人每晚选择一名存活玩家成为邪恶恶魔。

### 分类结论

- 不注册为普通智能板子。
- 原因：当前普通智能板子质量门要求 7-15 人标准人数构成和至少一个常规恶魔；该来源依赖传奇「凶宅」生成恶魔，属于特殊玩法小板。
- 后续可做：若用户明确需要，单独设计“小板/特殊模式”入口，允许非标准恶魔结构和专门主持提示。
