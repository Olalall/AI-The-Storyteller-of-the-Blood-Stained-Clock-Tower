## 1. 锁定结论

- 用户所说的“132 个”，在官方魔典的剧本选择面板中可复现。
- 接口：`POST https://clocktower.gstonegames.com/ct/grimoire_edition_list/`。
- 请求体：`{ tab, name: "", order: 1, page: 1, limit: 300 }`。
- `tab=1` 对应官方剧本：8条。
- `tab=2` 对应缝合剧本：77条。
- `tab=3` 对应原创角色剧本：47条。
- 合计：132条。

## 2. 与 Antiphoton 来源的关系

- Antiphoton 默认中文集合页面显示 1080 个脚本，不是本轮“132 个”的直接等价来源。
- 之前的虚拟列表采样只拿到 128 条，说明它不适合作为 132 条全量依据。
- 本轮改用官方魔典接口锁定 132 条队列。

## 3. 本轮已产出

- `gstone-edition-manifest.json`：132 条的紧凑清单，含 JSON URL、SHA-256、角色数和角色 ID 摘要。
- `IMPORT_QUEUE_132.md`：面向导入的人类可读队列。
