# Clocktower Wiki 第四批：共享角色复用

本批在统一角色库上新增十个组合，不再为每板复制角色技能资料。源码验收完成，最终上线状态以合并记录和部署回执为准；来源冲突、自制角色和特殊配板仍须单独核对。

## 来源和范围

2026-10-21 重新下载用户指定[剧本库](https://kkovo550.github.io/clocktower-wiki/script_lib/%E5%89%A7%E6%9C%AC%E5%BA%93.html)的目录与完整 JSON，字节摘要与既有锁定源一致。目录有 1,267 条版本记录、1,189 个剧本组；这两个数量口径不同。[官方角色资料](https://release.botc.app/resources/data/roles.json)和[官方夜表](https://release.botc.app/resources/data/nightsheet.json)也重新下载并确认摘要未变。

新增：旧日重现、不蛭之症、亡灵同好会、一寸短一寸险、贾方复仇记、由头来过、俯首称臣、温润良夜、身不由己、全球惊悚。智能板包由 138 增至 148。245 条角色引用全部复用既有共享定义，没有新增角色实现；每板分别保存原文、摘要、版本差异、完整角色定义指纹和验收记录。原 138 板的原始包与归一化结果逐项保持一致。

角色已经覆盖不表示配板模板可以照搬。这十板与现有模板连同原三项伪装的完整匹配数均为零；本批新增 220 套去重模板，逐个通过实际配座和确认校验，覆盖 90 个板子人数档，再复核人数修正、伪装和特殊组合。20 套首夜/后夜序与当前官方夜表交集一致；6 条适用相克与本轮重新取得的[官方相克表](https://release.botc.app/resources/data/jinxes.json)一致。

旧原文与当前规则不同的板子明确标注适配版本，包括炸弹人计时、暴乱转化时点及气球驾驶员人数修正。旧日重现的原文只有稳定 ID，未提供的能力文本和夜数在来源锁中保留为空；运行规则由已核官方资料与共享定义补齐，不补造原文事实。温润良夜复用的自制旅行者往生者锁定原有来源版本，不进入普通配座、伪装或自动夜序。

## 共用工具修复

修复薄板包注册后再次准备板子时，工具试图读取薄包同名角色目录的问题。薄包继续提供可复用模板，角色资料只从原有共享来源读取，不能用薄包的新名称伪装成一个新的角色版本。隔离回归实际生成并加载薄包、模拟注册后再次准备，检查来源绑定、模板复用和错误来源拒绝。

已有构建压缩测试加载器补齐 JSON 模块解析，保留全部 148 板压缩前后的完整深等断言；生产压缩逻辑不变。候选展示名去除混入的作者尾缀，作者资料仍保留在原文与来源。

## 实测带出的交互与技能核对

普卡提示明确区分旧目标追踪与当前毒效：毒醉期间旧毒暂停、旧目标不因此死亡，恢复能力后旧毒恢复。旧目标受到保护时先核对死亡是否被阻止，再确认旧毒结束；结果 ID、历史链和主持手动确认状态的边界保持。

首次离线准备提示出现时曾把正在点击的配板按钮推开。修复为预留一行紧凑通知空间，并保留完整的离线、更新和编辑保护提示。确定性测试在按下后才完成真实 SW 安装，再松开同一次点击；较长、多条动态提示仍可展开，不声称所有动态布局都固定。

农夫先核对本夜触发，未核对时不能录入结果或请求 AI。旧局未确认项会补上核对；农夫自身生死、毒醉变化后重新核对，无关玩家变化不会反复重置。新记录以当前持久队列校验，不能在提交数据里伪造认可。原确认历史继续保留，更正追加记录；不自动选择继任者或修改身份。特殊相克由主持另外核对，不能只凭当前存活状态一概阻止。

## 验收与发布

最终完整 `npm run check` 通过：370 个测试文件通过、2 个条件跳过，2,752 项测试通过、11 项条件跳过，lint、构建、PWA 与架构检查均通过。最终生产构建三引擎六项目浏览器 138/138 通过，无跳过、重试或不稳定通过。首次完整检查的 JSON 加载和中文标题两处失败、离线准备提示丢点击原始复现、跨引擎断网夹具误判及移动缩放浮点差异均保留。新增测试曾超出文件预算，已拆分后重跑完整检查，未放宽限制。断网测试改为隔离源真实断连并独立探测，不把合成的离线 UI 事件当作实体设备断网。

ego-browser 实际点击覆盖十板开局与不同人数、刷新保留，另核对了旧日重现首夜到次夜、投票与处决，痢蛭宿主及舞蛇换角当夜新能力，普卡失能与第三夜旧目标追踪。最终农夫修复后，又通过界面恢复同一旧局，确认未核对时禁用录入与 AI，不适用及刷新保留原记录和状态。十板开局在农夫修复前验收，最终修复单独复验；最终浏览器自动回归覆盖全部十板。共 428 次成功点击、按键、填写和选择，4 次操作失败单列；另外的滚轮、文件选择、等待或脚本断言不混入交互数量。这些包含局部流程和重复验收，本轮没有完整结束新局，也未实测实体手机。

真实 AI 已完成十个新板的十个隔离局部语义题，普卡文案修正后额外复核一次，再补一题农夫触发，合计 12 次请求、11 个主题、零自动重试。原始、后端归一化与前端三层共 36 层分别核对，真实状态保持不变。农夫专项用本批实际合法九人模板，先记录攻击与主持确认夜死，再核对适用，继任者存活且善良；模型只给待确认的换角草稿。三次中毒回答把字符串字段写成布尔值，均被安全降为纯文本，并补齐拒绝采用的回归；语义通过不等于所有结构化格式完美。这些局部题不计作完整自主对局。

源码与运行包不得含私人 API 地址、密钥、模型配置、对局或原始测试证据；线上只切换程序，保留现有对局、服务器数据和私人配置。
