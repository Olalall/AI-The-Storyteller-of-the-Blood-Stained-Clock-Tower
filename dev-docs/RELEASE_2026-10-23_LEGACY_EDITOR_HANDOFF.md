# 旧浏览器刷新交接

本轮优化没有 Web Locks 时的刷新与前台恢复，复用已有 IndexedDB 租约和存档原文检查。正常退出先永久关闭该编辑实例，再同步留下仅含随机编辑身份的退出凭据。新页面核对租约声明的交接协议、旧拥有者和当前存档后接手；异步删除租约丢失时也可恢复。仍活跃的其他标签不能被抢占，拿着旧内存的页面不能覆盖新记录。

只修改共用编辑锁，不新增依赖、强制接管按钮或第二套对局存储。不改变游戏规则、存档版本、AI 设置、邀请口令或设备授权。退出凭据只占一个固定键，旧凭据与新拥有者不匹配时无效；未取得租约的标签不发布退出凭据。

回归包含：无原生锁且异步清理丢失时连续刷新、多标签与复制标签排他、旧内容冲突、两个候选页同时切回争用、退出凭据不可写、缺失或未知交接协议、凭据与拥有者不匹配，以及已有返回缓存和保存失败路径。前台事件注入单列为模拟事件，不能代替实体 iPad 的系统切换测试。旧代码已用同一浏览器用例复现刷新后八秒仍不能保存的失败。

本地 2,998 项单元回归通过、23 项条件跳过，类型检查、生产构建、PWA 校验和后端启动 smoke 通过。首次架构检查指出新存储键未登记与已有测试文件超三行预算，已补登记用途并只压缩测试排版，架构与 lint 复查通过，相关十六项 hook 回归再次通过。

Ego 在独立地址实际点击十五人开局、改一条状态记录、三次刷新、第二标签刷新与切换、关闭原编辑页后接手，以及真实历史导航返回。兼容分支通过 CDP 模拟没有 Web Locks、异步删除不生效；三次刷新为 223、213、206 毫秒，第二页受保护时零次写入，接手后对局和恢复前副本原文保持。另在 507px 视口实际打开与关闭玩家状态面板，无横向溢出。Ego 窗口最小化无法截图，布局截图由单列的 WebKit 自动化检查提供，不算实体 iPad；这些步骤没有完成一整局，也未调用付费 AI。

三引擎及平板横竖屏、分屏共 111 个独立用例，最终 108 项通过、3 项因未命中真实脏数据返回缓存而条件跳过。其中 12 项涉及明确标记的合成前台或缓存事件，不算真机证明。覆盖连续刷新、排他编辑、旧内容冲突、备份恢复及保存失败；重复补测只更新对应用例结果，不累加宣传覆盖数。

首轮保留四条失败记录。Chrome 的退出拦截装在产品监听器之后，实际已经生成合法退出凭据；现将可开关的故障拦截放在应用启动前，并核对凭据确实缺失。退出不可确认的 close 不能当成快速交接前提，争用用例改用真实导航并核对退出凭据。冷启动准备与安全租约的等待分别限时，正常刷新和页面内前台恢复仍要求八秒内成功保存。

分屏补测另出现一次驱动往返超过八秒的失败，已保留原始报告。前台恢复改由页面时钟测量事件到首次成功保存，同时核对保存时保护面板已消失；驱动往返单独记录，另一页始终零写入。修正后的十五项故障/争用补测及十二项刷新/前台补测均完成，最终无待处理失败。

运行包已验收，正在发布；上线回执随后补充。

没有有效退出凭据、升级前旧页面、系统直接回收进程时，仍保留十五秒租约和五秒检查的安全兜底。实体 iPad 的系统键盘、锁屏、低内存回收和长局仍需真机确认；本轮不把 WebKit 尺寸模拟写成真机实测。
