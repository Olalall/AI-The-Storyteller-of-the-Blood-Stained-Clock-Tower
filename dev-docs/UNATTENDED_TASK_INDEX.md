# 无人推进任务索引

## 当前策略

按阶段推进，不按无限时间推进。每次无人推进都从本文件读取第一个 `Ready` 任务；完成后更新本文件。如果下一项仍是 `Ready` 且没有触发停止条件，可以自动继续。只有遇到 `Blocked` 或 `Needs User Review` 才停下。

## 状态定义

- `Ready`：可以无人推进。
- `In Progress`：当前正在推进。
- `Needs User Review`：需要用户验收或产品判断。
- `Blocked`：必须等用户明确授权。
- `Done`：已完成并有验收证据。
- `Draft`：已有草稿，但不能视为完成。
