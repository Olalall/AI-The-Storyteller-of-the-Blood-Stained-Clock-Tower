## 特殊开局与历史角色 ID

卡扎力初始只放恶魔与善良角色，不预放爪牙；首夜完整配对后仍须主持记录并显式应用，才更新当夜夜序。被替换角色未发动项停用，新爪牙按正确时点处理。召唤师开局无恶魔，第三夜再由主持确认变更；堤丰多一名爪牙，邪恶连续且自身两侧邪恶，不要求几何正中央。

换角的单人投影不再重复生成小怪宝照看／死亡项。已有军团时新增成员不增加整组行动次数；本夜已处理的整组行动保持已处理。用来关联整组记录的成员变成其他角色后，未处理项仍关联到剩余军团，能够正常确认。小怪宝的无座位步骤在切换、轮播、最近确认与关夜清单中不显示“0号玩家”，遮蔽时隐藏集体角色提示。
