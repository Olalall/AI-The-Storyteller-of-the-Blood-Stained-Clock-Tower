## 这一版解决了什么

- 支持作为 PWA 安装到 Android、iPhone 和 iPad 主屏幕，不需要 APK。
- 第一次联网完整打开后，可离线重开并继续使用配板、夜序、投票、日志和本机复盘。
- 首次使用流程改为“安装或试用 → 选择主持方式 → 开始配板”，回访用户直接进入精简入口。
- 新增当前对局 JSON 导出、导入预览、二次确认、兼容迁移和导入后撤销。
- 第二个浏览器标签页会真正进入只读状态，避免两个窗口互相覆盖同一局记录。
- API Key 保存到当前站点在当前浏览器里的本机存储；不会写入 GitHub，换设备或清除站点数据后需要重新填写。
- AI 连通测试不再把用户接入地址与 VPS Key 混用。
- 新增显式公网分享模式：匿名用户不能读取 VPS 归档、恢复数据或使用 VPS Key；可选 BYOK 只允许白名单中的 HTTPS provider，并有请求体与频率限制。
- 延续 2026-08-07 已合入的角色翻译、技能文本、首夜顺序和夜间 AI 规则一致性修复。

## 使用边界

- 这是社区制作的非官方说书人辅助工具，不是官方魔典，也不是完整自动规则引擎。
- AI 只生成候选、草稿和提示；身份、阵营、死亡、毒醉、处决与胜负仍由说书人确认。
- GitHub 下载版不附带 API Key、VPS 地址或官方/社区二进制素材包。
- 真实 AI、首次素材下载和云端能力需要联网；离线模式保留核心手动主持流程。

## 已知限制

- Android Chrome 与 iPhone/iPad Safari 真机安装仍需发布前人工确认；当前自动证据来自 Chromium 的尺寸、触控与 UA 模拟。
- 尚未把本提交部署到真实 VPS，也未验证真实域名、HTTPS 反向代理和公网限流表现。
- 反向代理后的用户可能共享 runtime 每分钟 10 次的 AI 请求限额，开放公共 BYOK 前需要按实际代理拓扑验收。
- 首次离线包约 6.2 MB；主 JavaScript 包仍有体积警告，属于后续性能优化项。
