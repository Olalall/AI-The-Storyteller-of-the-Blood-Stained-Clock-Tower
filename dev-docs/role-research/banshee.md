# 报丧女妖 / Banshee

状态：reviewed  
调研日期：2026-10-16  
来源：[官方角色页](https://wiki.bloodontheclocktower.com/Banshee)、[状态规则](https://wiki.bloodontheclocktower.com/States)。

健康清醒时被恶魔杀死才公开觉醒。处决、非恶魔杀死、死亡时失去能力均不触发。觉醒后每天最多发起两次提名；每一轮提名都可投两票，不限自己发起的提名，不是每天总共两票，也不需要或消耗普通死亡票。后续毒醉时能力暂时失效，按普通死者资格核对。

必填事实：死因和能力来源、死亡时毒醉、是否已觉醒、当前能力是否有效。主持确认觉醒与每轮票数，系统不自动加票或扣票。玩家告知使用完整单位；隐藏毒醉和资格核对备注只写主持提醒，不夹进可公开或照读的文案。
