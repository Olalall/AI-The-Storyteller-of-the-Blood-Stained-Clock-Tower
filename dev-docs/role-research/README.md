# 角色调研记录目录

本目录用于保存复杂角色的逐个调研记录。

## 使用规则

- 一个角色一个文件：`<roleId>.md`。
- 文件名使用稳定英文 ID，不使用中文名。
- 调研记录先写在这里，确认后再提炼到 `src/domain/scripts/**`。
- 这里可以写完整解释；代码里的结构化字段只放短摘要。
- 没有来源、来源冲突或规则不确定时，不能标成 `confirmed`。

## 禁止事项

- 不在这里写自动结算代码。
- 不把 AI 草稿当官方规则。
- 不把某个板子的临时判断复制成全局结论。
- 不用中文角色名做主键。

## 单角色模板

模板见：

```text
dev-docs/COMPLEX_ROLE_RESEARCH_PLAN.md
```
