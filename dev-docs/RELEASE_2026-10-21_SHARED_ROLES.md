# 共享角色支持与批量板子接入

本轮验收已完成；发布状态以 GitHub 合并记录和部署回执为准。

## 本轮范围

先修复完整主持点击实测发现的十项问题：

- 方古转变候选不能当作已经完成的首次转变。
- 已用死亡票不能在后续轮次再次计入；更正、撤销和复活需按有效历史核对。
- 酒鬼按已确认的对外镇民身份假装唤醒，保留实际身份和主持确认边界。
- 图书管理员可以正式记录没有外来者。
- 夜间直接录入正式数字和是非信息，保留旧记录和追加更正。
- 未触发死亡能力的月之子不制造缺少白天选择的警告。
- 历史提示投影幂等，不反复追加旧结论。
- 当夜角色变化按实际夜晚和主持选定时点显示。
- 复盘更正统计包括撤销票型，审计链完整保留。
- 本局记录进入当前会话日记，历史归档另有明确入口。

完成上述修复后统一角色资料入口，复用已有的输入、结果和历史约束。已有角色的新组合只需声明角色引用、来源、特殊规则和配板，不需要增加页面或技能分支。同名不同规则版本不能静默合并。保留按需加载，避免首屏引入全部自制角色。

## 数据与权限

角色库属于知识数据，不保存对局状态。既有角色、夜序、确认结果、身份变化和更正快照继续由原会话与时间线保存，不用新资料重写历史。AI只生成候选，不能自动改变身份、阵营、生死、毒醉、投票、胜方或阶段。

生产发布只替换程序，并在切换前备份当前数据和可恢复程序。公开源码、测试、文档和附件均不得包含私人上游地址、模型配置、密钥、口令、部署标识、个人路径或真实对局。

## 角色复用与旧资料兼容

138 个已注册板包的角色定义移到独立 `role-library/<来源分组>/roles.ts`，旧 `packs/*/roles.ts` 保留兼容导出。全部 138 个原始板包和 138 个正规化板包在迁移前后逐项完全相等，包含 3,662 条角色引用、夜序和模板；完整快照的前后 SHA256 均为：

```text
65d8490d673ba8c5e692cfe5ab9f6da356fb822bf9f9df798490228b3fcdd3c6
```

共享索引覆盖 705 个归一后的角色 ID，131 个核心角色使用明确的优选定义。不同来源的同 ID 规则仍保留版本差异，不能据此把 705 个 ID 当作 705 套自动结算技能。角色库不接触对局状态，浏览器保持按需加载。

离线准备工具只生成待核对板包、来源引用、完整角色定义指纹和候选模板。未知角色、无法消歧的版本、自制角色缺夜表等情况会阻止准备。生成目录不覆盖已有数据，不修改注册表；板包保持 `needs-review`，模板保持 `verified: false`。注册后，清单和构建会检查角色指纹，资料变化必须重新核对。现有 138 个板子的已核实状态不因这次迁移改变，也没有自动新增正式板子。
