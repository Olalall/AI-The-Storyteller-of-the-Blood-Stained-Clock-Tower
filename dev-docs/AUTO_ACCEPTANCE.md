# 一键自动验收

在 React 新版项目根目录运行：

```powershell
npm run verify:auto
```

使用项目已有依赖和已安装的 Playwright Chromium；不自动安装依赖或浏览器。缺少依赖时按日志处理。本命令不部署、不调用真实 AI，不连接日常浏览器存档。

## 自动执行

1. 检查项目包名，以脚本所在目录为根目录，避免从旧 V2.5 工作目录误启动。
2. 运行代码检查、架构检查和单元测试（真实 AI 测试关闭）。
3. 创建本轮专用的生产构建，不覆盖现有 `dist` 或局域网预览。
4. 在 `127.0.0.1:4287` 启动严格端口预览，逐字比对网页与本轮构建的 HTML，并保存 SHA256。端口被占用时失败，不复用其他服务、不自动换端口。
5. 运行 `tests/load-performance` 现有浏览器用例：完整对局、六昼夜触控模拟、备份恢复、编辑冲突、保存失败、剧本延迟加载和加载失败、HTTP UUID API 缺失兼容性。
6. 输出中文汇总和 Playwright 操作报告。测试服务由 Playwright 在结束时关闭。

每个浏览器用例使用独立上下文中的测试局；操作确认仅写测试局。默认 2 个浏览器工作进程、失败不重试，避免用重跑掩盖问题。前置步骤失败时，后续标记“未执行”，命令返回非零退出码。正常结束只在所有步骤成功时标记通过。

## 查看结果

每轮目录：`.codex-artifacts/auto-acceptance/<时间>-<进程号>/`。不覆盖上一轮证据，不自动删除报告。该生成目录已从 Git 和代码检查中排除，报告自带的第三方网页代码不会污染下次检查。

- `summary.md`：中文汇总、通过/失败/未执行、耗时和未覆盖项。
- `summary.json`：可供工具读取的汇总。
- `*.log`：各检查步骤的输出，包括单元测试跳过数量及架构存量警告。
- `entry.json`：入口地址与本轮 HTML 哈希。
- `html/`：逐项测试详情；浏览器失败时保留截图和操作轨迹，可查看出错前后的页面。
- `browser-results.json`、`browser/`：原始结果与附件。
- `dist/`：对应本轮验收的构建。

使用报告中的 `npx playwright show-report ".../html"` 命令查看交互式详情。进程被强制结束或电脑断电时，可能没有最终汇总；没有汇总不代表通过。报告会包含隔离测试局的身份和操作，请按项目测试资料保管。

## 范围限制

浏览器尺寸和触控模拟不能证明真实手机软键盘、后台恢复与触摸手感通过；这一步不检测 VPS、真实设备局域网连通性、真实 AI 服务质量，也不是全部 117 个剧本的语义验收。对应人工检查见 [真机验收入口](DEVICE_ACCEPTANCE_START.md)。
