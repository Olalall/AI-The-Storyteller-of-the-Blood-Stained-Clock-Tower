# Community asset pack directory

This directory is reserved for optional local community visual assets.

Public repository boundary:

- Do not commit binary community assets here by default.
- Keep only this README, manifests, hashes, or source notes.
- Import or download visual assets only after the user confirms source, usage, and disclaimer.
- Missing assets must not block setup, night order, voting, journal, archive, or AI suggestions.

本目录用于本机可选社区素材包。

- 默认不要提交社区二进制素材。
- 只保留 README、manifest、hash 或来源说明。
- 下载/导入前必须让用户确认来源、用途和免责声明。
- 缺素材不能阻塞开局、夜序、投票、日志、归档或 AI 建议。
